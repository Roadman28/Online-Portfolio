Page Details

  • Home Page - This page provides a brief overview of the user's skills, featuring a grading scale to highlight proficiency, along with experience and contact information.
  • Resume Page -This page highlights the user's professional background, showcasing their mission, work experience, education, skills, and references. It serves as a comprehensive resume-style portfolio with a focus on their expertise and qualifications.
  • Personality Page - This page showcases the user's personality, including their best attributes, a favorite motivational quote, and the results of their personality test. It provides insights into their logical and determined mindset, as well as how they approach challenges and personal growth.
  • Personal Development Page - This page summarizes and reflects on Chapters 4-7 of Twelve Pillars by Jim Rohn and Chris Widener. It also includes a section detailing the user's degree in Computer Information Systems (Data Analytics) and highlights the top skills acquired from the degree.
  • Storyboard Page - This page highlights the Website Flow Chart, Page Details, Website Theme, Website Features, and Hosting Link sections, providing an overview of the user's website structure and design.
  • Reference Page - This page includes the references, sources, and key information used to develop and design the website.

    • Website Theme

    The website theme is designed to be professional, clean, and visually appealing. The color scheme consists of dark backgrounds ( #181818 for the body, #222222 for the navigation and footer, and #2a2a2a for section cards) with light text ( #e5e5e5) to ensure readability and contrast. The layout is structured and organized, with clear sections and navigation, featuring a gradient header ( #1f1f1f to #2d2d2d) to guide users through the content. The use of icons, images, and hover effects (such as #00bcd4 for link hover states) helps to enhance the visual appeal and engage users with the information presented.

    Website Features

  • Image Gallery: For displaying images such as charts, icons, and other visual elements (e.g., flow chart, page details, and theme images).
  • Navigation Menu: A structured navigation bar for easy access to different pages (e.g., Home, Resume, Personality, Personal Development, Storyboard, References).
  • Hover Effects: Visual interactions like link hover states, where colors change to enhance the user experience (e.g., #00bcd4 for link hover).
  • Drop Shadows and Hover Effects on Cards: Provides interactivity and aesthetic appeal through effects like scaling and shadow changes on hover (e.g., summary cards).
  • Text Content Sections: Structured text content to showcase detailed information in the form of lists and descriptions (e.g., Page Details and Website Theme sections).
